# Integrity MVP

This repository contains the high-fidelity proof-of-concept frontend for the Integrity Protocol. It serves as a business-ready demonstration for developers and investors, bridging the gap between cryptographic telemetry (ZK proofs, TEE attestations, AIS scores) and real-world user experiences.

## Project Structure

This project is built using React (Vite) and TypeScript, following the architecture defined in the `integrity_mvp_plan.md` document.

- **`landing_page_strategy.md`**: Outlines the content strategy and UI flow for the Landing Page.
- **`integrity_mvp_plan.md`**: Defines the overall product scope, visual design principles, and technical architecture.

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the development server:
   ```bash
   npm run dev
   ```

## Features

- **Global Agent Context**: Instantly switch telemetry views between different agents in the registered fleet.
- **Visual Identity & XNS**: Mint and manage human-readable `.xibalba` domains.
- **Interactive AIS Metrics**: Deep dive into the Agentic Integrity Score with live mathematical visualizations.
- **Xibalba Shield & Integrity Health**: Enterprise verticals demonstrating OPA policy interceptions and HIPAA compliance.
- **DeFi Integration**: Interact with `$ITK` staking, slashing, and the Decentralized Capital Allocation markets.
